# Brand assets

Drop the MiniMines brand guidelines PDF and any logo files here.

    brand/
      MiniMines-Brand-Guidelines.pdf   <- the PDF
      logo/                            <- SVG preferred, PNG fine
      service-marks/                   <- per-service logos, if any exist

Once the PDF is here, the console design directions get built from it: colour, typography,
logo lockups, spacing and tone. Until then the demo uses a placeholder palette taken from
the refined products (nickel sulfate teal, cobalt rose, graphite) which is explicitly
temporary.
